The method

The FDE skill set is a braid of four strands no university teaches together: full-stack speed, data wrangling, enterprise deployment, and customer craft. Every lesson trains at least one strand against realistically messy data.

01Real problems, not toy problems

Every drill uses synthetically-generated messy data: duplicate customers, three date formats, Excel-mangled IDs, feeds that don't arrive. Because that is the job.

02Self-testing, zero setup

All code is Python stdlib only — nothing to install, no API key. Every flagship and drill asserts its own correctness: python lesson.py passes or tells you exactly what broke.

03Interview-first theory

Every theory lesson maps to questions asked in real FDE loops — Palantir decomp, OpenAI forward-deployed, Anthropic applied AI, Scale, Sierra. The interview bank has 150+ answered questions.

04Six-beat lessons

PROBLEM → INTUITION → BUILD IT → FIELD NOTES → INTERVIEW ANGLE → DRILL. War story in, interview signal out.

05MockLLM for the AI parts

RAG, structured extraction, and eval harnesses ship with a deterministic, scriptable MockLLM — the harness engineering is unit-testable on your machine.

06The capstone spine

Capstone 1 simulates a full engagement at a fictional hospital network — discovery transcript to handoff runbook. The other five retrofit onto it.
