# Roadmap — three tracks

Pick the track that matches your runway. All tracks cover the interview bank;
the longer tracks go deeper on drills and capstones.

## 6-week sprint (interview in ~6 weeks) · ~60h

Goal: pass an FDE loop. Theory + interview bank + enough building to talk credibly.

| Week | Focus |
|------|-------|
| 1 | Phase 0 (all) + Phase 1 lessons 01–06 |
| 2 | Phase 2 flagships (01, 08) + Phase 3 flagships (01, 05, 08) |
| 3 | Phase 5 flagships (01, 04, 06) + Phase 4 lessons 01–03 |
| 4 | Phase 8 (all) + case-interviews.md worked cases |
| 5 | Phase 9 (all) + theory-questions.md, two passes |
| 6 | Drills 03, 04, 08, 12 + mock loop (Phase 9 lesson 12) + behavioral stories |

## 12-week standard (default) · ~120h

Goal: interview-ready **and** field-ready. Everything except deep capstones.

| Weeks | Focus |
|-------|-------|
| 1 | Phase 0 + Phase 1 first half |
| 2 | Phase 1 finish + Phase 2 first half |
| 3 | Phase 2 finish + Phase 3 lessons 01–07 |
| 4–5 | Phase 3 finish + Phase 4 |
| 6–8 | Phase 5 + Phase 6 |
| 9–10 | Phase 7 + Phase 8 |
| 11 | Phase 9 + interview bank, two passes |
| 12 | Drills 01–08 + Capstone 1 (pilot-in-a-box) |

## 18-week mastery · ~180h

Goal: operate as a first-year FDE on day one.

| Weeks | Focus |
|-------|-------|
| 1–2 | Phases 0–1, write your own engagement-lifecycle notes |
| 3–4 | Phase 2 + Phase 3 lessons 01–07 |
| 5–6 | Phase 3 finish + Phase 4 |
| 7–9 | Phase 5 + Phase 6 |
| 10–11 | Phase 7 + Phase 8 |
| 12 | Phase 9 + full interview bank |
| 13 | All 12 drills |
| 14–15 | Capstone 1 (the spine) |
| 16–17 | Two capstones of your choice (2–6) |
| 18 | Mock loop, portfolio polish, proof-of-work write-ups |

## Sequencing rules

- Phase 3 before Phase 5: RAG on data you can't ingest is theater.
- Phase 8 before Phase 9: the decomp method is the interview.
- Drills any time after their feeding phase (each drill README names it).
- Capstone 1 before capstones 2–6: they retrofit onto its scenario.
